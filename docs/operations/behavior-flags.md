# Root-owned cross-cutting behavior flags

Canonical long-form reference for the **root-owned cross-cutting** behavior flags
(`DECISION_*` / `ED4ALL_*` / `LOCAL_DISPATCHER_*` / `MCP_ORCHESTRATOR_*` / `LLM_*`). Split
out of the root [`CLAUDE.md`](../../CLAUDE.md) for context-size reasons: the root file keeps a
compact, grep-able one-line index of these same flags under **§ Opt-In Behavior Flags →
Cross-cutting flags (root-owned)**, and THIS file carries the full per-flag detail (resolution
chains, guardrails, calibration status, anti-fabrication contracts). Subsystem-prefixed flags
(`TRAINFORGE_*` / `LOCAL_SYNTHESIS_*` / `TOGETHER_*` / `ANTHROPIC_SYNTHESIS_*` / `CURRICULUM_ALIGNMENT_*` /
`WAVE18_*` / `NVIDIA_*` / `SEMANTIK_*` / `COURSEFORGE_*` / `COURSEPLANNER_*` / `TEXTBOOK_SYNTHESIS_*`) stay
in their owning subsystem `CLAUDE.md` files.

Counting convention for THIS table: **one row per flag** (count equals row count) — it
documents **219** root-owned cross-cutting flags. (The subsystem CLAUDE.md tables use the
separate "distinct flags, multi-flag rows expanded" convention documented in root
`CLAUDE.md § Opt-In Behavior Flags`.) Satellite knobs
named only inside a parent flag's Purpose cell (and the excluded vars listed in the trailing
paragraph below) are not counted.
