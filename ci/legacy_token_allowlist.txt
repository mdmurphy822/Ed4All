# Legacy 'dart' token allowlist  (ci/legacy_token_guard.py)
#
# The guard fails when the retired engine name ``dart`` (any casing) appears
# in a tracked file that is not listed here. ``DART`` was the AGPL PDF->HTML
# engine ``SemantiK`` replaced. EMIT / write paths are dart-free: converted
# HTML carries ``data-semantik-*`` attributes, chunk source-ids are minted
# ``semantik:{slug}#{block_id}``, the on-disk chunkset dir is ``semantik_chunks/``,
# and freshly-emitted manifests stamp ``semantik_chunks_sha256`` /
# ``chunkset_kind:"semantik"``. Every file below carries the token for one
# reason only: a load-bearing dual-READ / migration / wire-contract literal
# that must survive so 19 un-migrated local corpora + 230 old checkpoints +
# paused resume state keep validating. There is NO "scrub-pending" ratchet:
# each entry is an individually-justified WHAT-MUST-STAY surface.
#
# Format (one per line, '#' starts a comment):
#   <repo-relative-path>            allow every 'dart' match in that file
#   <repo-relative-path><TAB><tok>  allow exactly one matched spelling there
#
# The guard's own module + test and this allowlist are always self-exempt
# (``_SELF_PATHS``) and need no entry. Prefer an inline ``legacy-token: allow``
# marker on a single doc line over allowlisting a whole doc.
